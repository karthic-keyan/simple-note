# Privacy Policy for Simple Note

**Last updated:** October 2026

Simple Note ("the Application") is an offline-first desktop note-taking application designed with complete user privacy in mind.

---

### 1. Zero Personal Data Collection
Simple Note does not collect, track, transmit, or sell any personal data, usage metrics, telemetry, or user behavior.

### 2. Local Storage
- All your notes, notebooks, tags, preferences, and backups are stored **100% locally** on your personal device in an SQLite database.
- None of your content is uploaded to any external server or cloud service.

### 3. Network Access
Simple Note runs completely offline. Network access is only triggered when you explicitly click an external hyperlink inside a note, which opens in your default web browser.

### 4. Data Security & Control
- You maintain complete ownership and control over your data.
- You can export, backup, or permanently delete your notes at any time from within the app.
- Uninstalling the application does not delete your local SQLite database file unless explicitly chosen by you.

### 5. Contact
If you have questions regarding this Privacy Policy, please open an issue on our GitHub repository or contact the Simple Note development team.
